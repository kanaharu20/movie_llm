# 演習: おもちゃモデルで GRPO + LoRA を自分で組み立てる

本物の学習ループ（`movie_llm/train/grpo.py`）と同じ構造を、CPU で数秒で回る小さな問題で再現する。目的は、発表で「学習の仕組み」を自分の言葉で説明できるようになること。読み物は Artifact「movie_llm 学習ノート」の第 9 章。

| ファイル | 内容 |
|---|---|
| `toy_grpo.py` | 完成版。まず動かして出力の読み方を覚える |
| `toy_grpo_exercise.py` | 穴埋め版。報酬・advantage・LoRA・損失の 4 か所を自分で書く。`--check` で答え合わせ |

## 問題設定

- 「動画」は長さ 16 の出来事の列（各フレームに 0〜5 の出来事番号が 1 つ。一部は「ぼやけて見えない」）
- 「問い」は探す出来事の番号。答えは「その出来事が映っているフレーム番号」（本物の「場面の時刻」に相当）
- 報酬は本物の `score_time` と同じ形: 正解 ± 許容幅（1 フレーム）なら 1.0、外れた距離で線形に減って 0
- 学習前モデルは「正解が前半（0〜7）にしか無いデータ」で教師あり学習した偏ったモデル。後半に正解がある問題が苦手（学習前 48%）。本物で「室内の演技映像で学んだことが日本の映像に移らない」のと同じ種類のずれ
- GRPO は LoRA（r=2、全パラメータの 11%）だけを更新する。LoRA を外すと元のモデルに戻る

## 進め方

```bash
uv run python learn/toy_grpo.py                 # 1. 完成版を動かす（約 5 秒）。学習前 48% → 学習後 約 88%
uv run python learn/toy_grpo_exercise.py --check  # 2. 穴埋め版の答え合わせ（最初は 4 つとも NG）
#   課題 1〜4 を上から順に書き、--check が「すべて OK」になるまで直す
uv run python learn/toy_grpo_exercise.py        # 3. 自分の実装で学習を回し、完成版と同じ推移になるか見る
```

## 出力の読み方

```
 step   報酬  正解率      KL entropy draws skip  貪欲法
    1  0.406  0.406  0.0000   0.884    12    8  48.4%
  100  0.920  0.906  4.6413   0.206    12   10  83.8%
```

- 報酬・正解率: サンプリングした 8 本の回答の平均（学習中の様子）
- KL: 参照方針（LoRA を外したモデル）からどれだけ離れたか
- entropy: 答えの分布のばらつき。最大 2.77（16 択で一様）。0 に近いほど毎回同じ答え
- draws / skip: 1 ステップに引いた問題数と、全員同じ報酬で飛ばした数（動的サンプリング）
- 貪欲法: いちばん確率の高い答えで測った 2,000 問の正解率。学習前後の比較に使う値（本物の dev / ベンチマークに相当）

## 観察課題（引数を変えて、何が起きるか説明する）

| 課題 | コマンド | 見るもの |
|---|---|---|
| 5. KL なし | `--beta 0` | entropy の下がり方と KL の跳ね方。β はどんな役目か |
| 6. 部分点なし | `--partial 0` | 序盤の学習信号（skip の数）。部分点は何を増やすか |
| 7. 偏りのない学習前モデル | `--pretrain-max-pos 16` | 学習前から 87%。GRPO で伸びるか。伸びないなら理由は |
| 8. 温度 | `--temperature 0.5` | 最初から skip が多い理由。サンプリングの多様性と学習信号の関係 |
| 9. 学習率 | `--lr 2e-2` | 速く上がるが途中で下がる。KL が nan になるステップは何が起きたか |
| 10. 回答数 | `--group-size 2` と `--group-size 16` | グループが小さいと advantage がどうなるか |

本物との対応（本物では何に当たるか）を考えながら進めると、発表の質問に答えやすくなる。例: 課題 7 は「Perception Test で学んでもベンチマークが動かなかった」こととは逆向きの話で、「学習前にできることは GRPO では伸びない」ことを示す。
