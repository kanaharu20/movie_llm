# GRPO 3 回目: 場面の時刻を当てる課題（2026-10-15〜16、Colab A100）

用途を「問いが指す場面の時刻を答える」に絞ってからの最初の学習。日本の CC BY 動画 1,000 本から作った場面データ（`docs/ja_data.md`）で 4B を GRPO + LoRA で 400 ステップ学習し、4 つの評価で判定した。

## 設定

- 学習データ: `data/ja/train_time.jsonl` 3,145 問（845 本）。dev: `data/ja/dev_time.jsonl` 330 問（93 本、動画単位で分離）
- モデル: Qwen3-VL-4B-Instruct、LoRA r=16 α=32（33.0M パラメータ）、32 フレーム（長辺 640）
- 出力: 根拠 1〜2 行 + 「答え: 分:秒」（max_new_tokens 96）
- 報酬: `score_time`（正解区間 ± 許容幅で 1.0、外れた秒数 d で max(0, 1 − d/30)）+ 形式 0.1
- GRPO: G=8、4 問/ステップ、動的サンプリング（上限 12 問）、lr 1e-5、β 0.04、温度 1.0、micro_batch 2
- 400 ステップ、1 ステップ 119 秒、合計 12.3 時間。Colab Pro A100（5.3 ユニット/時、約 65 ユニット）。評価 3 本で約 2.5 時間
- ノート: `notebooks/colab_grpo3_time.ipynb`。LoRA は Drive の `grpo3_time/step_00400`

## 読み方

1. **学習は機能し、同じ分布に汎化した。** dev +21.8 は揺れ ±5.5 の 4 倍。6 領域すべてで上がっている
2. **本番にも移った。** +6.8 は揺れ ±3.7 を超える。short と medium が同じ幅で上がり、4 択は変わらない（元の能力は壊れていない）。用途を絞る前の 2 回（dev は上がり本番は 0）とは違い、題材を本番に合わせた効果が出た
3. **判定の基準「10 ポイント」には届かなかった。** dev +22 に対して本番 +7 で、まだ分布のずれがある。考えられる差は、(a) 学習データの問いは 235B が書いた「場面の説明」で、本番の問いは人が直した「質問文」（「〜はいくつありますか」のように場面を指す言い方が間接的）、(b) 学習データは 235B が 2 回当てられた場面に絞ってあり、本番より当てやすい場面に偏っている
4. **medium の外れ方が変わった。** 当たらなかった問題でも距離の中央値が 39.5 秒 → 16 秒に縮んだ。粗く当てる力は上がっており、許容幅（8.4 秒）の内側に入れる細かさが足りない。32 フレームで 20 分を見る間隔（37.5 秒）が上限になっている可能性
5. **学習データ上の当たり率は 200 ステップで頭打ち。** 同じ設定で 800 まで延ばしても伸びは小さいと見込む
6. 指示文の例「12:03」をそのまま答えた回答が 12 問（当たり 1、学習前は 6）。「0:00」と答えた 139 問のうち 109 問が当たり（冒頭に正解がある問題が多い）

## 64 フレームでの評価（学習なし、2026-10-16）

学習後のモデルと学習前のモデルを 64 フレーム（間隔は 32 枚の半分）で同じ 722 問に当てた。`notebooks/colab_eval64.ipynb`。許容幅は 64 枚だと狭くなる（medium の中央値 8.4 秒 → 5.0 秒）ので、**32 枚と同じ許容幅で採点し直した値**も併記する（`predictions_tol32.jsonl`）。

| | 32 フレーム | 64 フレーム（64 枚の許容幅） | 64 フレーム（32 枚と同じ許容幅） |
|---|---|---|---|
| 学習前 全体 | 55.4% | 62.0% | 63.6% |
| 学習前 medium | 32.5% | 37.0% | 40.2% |
| **学習後 全体** | 62.2% | **69.9%** | **72.4%** |
| **学習後 medium** | 39.3% | **51.0%** | **55.8%** |
| 学習後 short | 83.8% | 87.9% | 88.1% |

同じ許容幅（32 枚基準）での効果の分解:

- 学習の効果: 32 枚で +6.8、64 枚で +8.8。フレームを増やしても学習の効果は消えず、むしろ少し大きい
- フレームの効果: 学習前で +8.2、学習後で +10.2。学習後のモデルの方がフレーム増の恩恵が大きい（「粗く当てる力」が上がっているので、細かく見せると許容幅に入る）
- 両方で **55.4% → 72.4%（+17.0）**、medium は **32.5% → 55.8%（+23.3）**。同じ問題での対応づけは直った 152・崩れた 29
- 64 枚どうしの対応づけ: 直った 92・崩れた 28（学習の効果）。学習後の 32 → 64 枚: 直った 104・崩れた 30

読み方: 判定の基準「学習で 10 ポイント」は学習単独では届かない（+7〜9）が、学習 + 64 フレームで本番は 17 ポイント上がる。製品としては「学習した LoRA を 64 フレーム（1 問 4 秒）で使う」が現時点の最良。評価の 1 問あたりの時間は 32 枚 2.5 秒 → 64 枚 4 秒。
