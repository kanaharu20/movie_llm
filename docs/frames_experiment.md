# フレーム数の実験（Qwen3-VL-2B、4択・yes_no 232問、規則採点）

学習に入る前に、入力の設定だけでどれだけ変わるかを確かめた。設定はフレーム数以外すべて同じ（長辺 640px 以下、1フレーム最大 256×28×28 画素、bfloat16、MPS、貪欲法）。

| 区分 | 問数 | 16フレーム | 32フレーム | 64フレーム |
|---|---|---|---|---|
| 4択 | 220 | 59.1% | 67.3% | 70.9% |
| yes_no | 12 | 75.0% | 75.0% | 66.7% |
| count | 51 | 51.0% | 60.8% | 58.8% |
| temporal | 49 | 59.2% | 69.4% | 77.6% |
| spatial | 81 | 60.5% | 67.9% | 69.1% |
| action | 40 | 65.0% | 67.5% | 75.0% |
| causal | 11 | 81.8% | 90.9% | 90.9% |
| short | 131 | 61.1% | 68.7% | 71.0% |
| medium | 101 | 58.4% | 66.3% | 70.3% |
| 動画トークン数（中央値） | | 1440 | 2880 | 5760 |
| 1問の秒数（M2 Pro） | | 5.2 | 8.2 | 18.6 |

## 読み取り

- 16 → 32 で 4択が 8.2 ポイント、32 → 64 でさらに 3.6 ポイント上がる。伸びは鈍るが止まらない
- temporal は 59 → 69 → 78% と一貫して伸びる。時間の前後関係はフレームが多いほど追いやすい
- count は 32 で頭打ち（61 → 59%）。数える問題はフレーム数より「見分ける力」の問題が残る。学習で狙う場所として妥当
- medium の伸び（58 → 70%）は short（61 → 71%）と同程度。長い動画だけが得をするわけではない
- yes_no は 12問しかなく、1問の違いで 8 ポイント動く。差は誤差の範囲
- 64フレームは 1問 18.6 秒で、16フレームの 3.6 倍。学習時は 32 が現実的な落としどころ。評価は 64 でも回せる

## 学習方針への影響

- ベースラインの公式比較は 16フレームで取ったが、学習の比較は 32フレームで揃える
- 「学習前 32フレーム」と「学習後 32フレーム」を比べれば、学習の効果だけを切り分けられる
- open と公式比較（GPT-4o 採点）も 32フレームで取り直す必要がある
