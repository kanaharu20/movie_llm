# ベースライン: Qwen3-VL-4B-Instruct（Colab A100）

2026-10-11。Colab Pro の A100（40GB）で、フレームキャッシュ（JPEG）を入力に 722問を予測。4択・yes_no は規則採点、open は GPT-4o（Vercel AI Gateway 経由）で採点。設定はフレーム数以外 2B と同じ（長辺 640px 以下、1フレーム最大 256×28×28 画素、bfloat16、貪欲法、max_new_tokens=64）。

## 読み取り

- 2B → 4B（同じ 16フレーム）で 5 ポイント、16 → 32フレームで 4 ポイント。モデルを大きくするのとフレームを増やすのが同じくらい効く
- **count は 4B でもほぼ伸びない**（39 → 42 → 43%）。モデルの大きさでもフレーム数でも解けない。学習で狙う場所として最有力
- temporal と action はフレームで伸びる。spatial はモデルの大きさで伸びる
- medium は short より 15 ポイント低いまま。長い動画は 32フレームでも足りない
- 食文化は 32フレームで 13 ポイント伸びた。調理の手順は時間方向の情報が要るためと考えられる
- 4択の「常に B」(40.7%) との差は 28 ポイント。4択だけ見れば 4B は十分に映像を見ている

## 考察（この結果から読み取れること）

1. **差は open にある。** 4B（32フレーム）45.8% と Gemini 3 Pro 76.3% の差 約 30 ポイントのうち、大半はベンチマークの 68% を占める open（35.1%）にある。4択は 68.6% で「常に B」を 28 ポイント上回り、映像はそれなりに見えている。open の失敗は読み取りの誤り（白をピンク、猫をキリン）が大半で、差の正体は言語や形式ではなく、映像を細かく見分ける力
2. **入力で取れる分と取れない分。** フレーム倍増で約 4 ポイント、2B → 4B で約 5 ポイント。temporal・action・食文化はフレーム数に、spatial はモデルの大きさに反応する。時間方向の問題は「見せる量」で、空間の問題は「見分ける力」で解けている。推論時のフレーム数は学習なしでできる改善で、製品では長い素材ほどフレームを増やす設計が合理的
3. **学習で狙う場所は count。** 2B 16f 39% → 4B 32f 43% とほぼ動かない。2B の分析では過小が過大の 2 倍以上。数える問題は「同じ対象を別のフレームで同一と認識し、重複なく数える」手続きが要り、見せる量では解決しない。正誤判定が確実にできる形式でもあり、GRPO の報酬設計と最も相性がよい
4. **「日本の映像に特化」への示唆。** 伝統文化が 57.4% で最も高く、自然・風景と四季・行事が低い。日本固有の知識はすでにある程度持っていて、ボトルネックではない。低いのは風景や行事の中の人や物の読み取りで、映像理解一般の課題。`docs/ideas.md` 案 6（海外の映像も学習に使う）を後押しする。問いの立て方は「日本語で日本の映像を読み解く小型モデルの精度を上げる」が実態に合う
5. **現実的な目標値。** 先行研究（Video-R1 など）では 7B 級への動画 RL で主要ベンチマークに 5〜10 ポイントの改善。4B で同程度なら 32フレームで 50% 台前半、推論時 64フレームで 50% 台後半が射程。公式 4B（54.5%）を超え Qwen3-VL-8B（56%）に並ぶあたりが成功の目安。Gemini との差を半分に縮めるには count と medium の両方で 10 ポイント以上が必要で、高い目標
6. **信頼区間。** 722問の正解率の 95% 信頼区間は約 ±3.6 ポイント。学習後の 2〜3 ポイントは偶然の範囲。同じ問題での前後比較（対応のある比較）と、カテゴリ別に一貫して上がっているかで判断する。count 188問は ±7 ポイントなので、count 特化の改善は 10 ポイント以上の差が要る
7. **実務的な結論。** 基準は「4B・32フレーム・45.8%」で固定。学習データは count と temporal の比率を上げ、題材は海外の映像でよい。学習中の進捗は 4択・yes_no 232問の規則採点（無料、20分）で追い、open の採点は節目だけ。推論時のフレーム数は製品側の調整項目として残す
